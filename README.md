# cse3153-database-project

CSE 3153 Fall 2026 Semester Project - SQL Server database (`AutoServiceShopDB`, schema `garage`) and C# console app.

## How to Run
1. Open `FinalProject.sql` in SSMS 22 connected to `localhost` and run it to create `AutoServiceShopDB` and sample data.
2. Open `AutoServiceShopApp/AutoServiceShopApp.sln` in Visual Studio 2022 and run the app.
